# IRONLEVEL Fitness Experience

## Build
- Replace the blank page with a responsive, dark premium dashboard centered on today's workout and next action.
- Add distinct Bodybuilding and Powerlifting mode cards, realistic profile metrics, XP, level, streaks, PRs, and weekly progress.
- Build an interactive workout panel with set completion, weight/reps inputs, RPE, previous performance, progression cues, and a working rest timer.

- Use a charcoal performance interface with electric lime for core progression, warm red for powerlifting, and cool cyan for bodybuilding.
- Use bold condensed display typography, compact athletic labels, restrained card radii, and subtle grid/gradient depth.
- Keep semantic design tokens in the global design system and use existing interface controls and icons.
